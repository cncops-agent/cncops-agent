# DESIGN.md · cncops-agent 路演 PPT

## 1. 设计基调
- **风格**：深色工业科技风（科技商务风分支的"深色变体"）——硬核、可信、车间感。
- **一句话定位**：给中小加工厂的"设备医生"，只读、离线、经验可沉淀。
- **视觉锚点规则**：每页至少一个 ≥44px 元素或 ≥40% B 区面积的图/大数字。

## 2. 画布与母版（1280×720）
| 区 | 位置 | 高度 | 内容 |
|---|---|---|---|
| 顶状态条 | top:0 | 6px | 青色高亮条（全篇统一） |
| A·标题块 | top:24 → 88 | ~64px | 左：PART 标签 + 主标题；右：英文小标 |
| B·内容区 | top:110 → bottom:54 | ~556px | 正文/图/卡/表 |
| C·页脚条 | bottom:0 → 44 | 44px | 左「cncops-agent · 只读诊断」+ 右「NN / 20」 |

- 安全区 padding 左右 60px；封面/封底可自定义。
- 内容页标题位置、页码位置**全篇严格一致**。

## 3. 颜色系统（色彩池）
| 角色 | hex | 用途 | 面积 |
|---|---|---|---|
| 主色（背景） | `#0F1B2D` | 页面底色、大色块 | ≤60% |
| 辅色（钢蓝） | `#2E5C8A` | 卡片底、分隔、图表第二系 | ≤30% |
| 强调（青） | `#22D3EE` | 焦点数字、标题标签、高亮列、CTA | ≤10%（hero 可达15-20%） |
| 报警红 | `#FF4D4F` | 仅"危险/报警/L3"语境 | ≤5% |
| 文本亮 | `#E6EEF5` | 标题/正文 | 中性 |
| 文本弱 | `#8FA3B8` | 注释/页脚/副信息 | 中性 |

- **渐变**：卡片头/标题区可用 `linear-gradient(135deg,#2E5C8A,#1E3A5F)`；半透明覆盖 `rgba(34,211,238,0.08)`。
- **网格底纹**：封面/封底用 `rgba(255,255,255,0.045)` 34px 方格（SVG 或 Box 模拟）。

## 4. 字体系统
- 标题/正文统一：**微软雅黑（Microsoft YaHei）**。
- 字号阶梯：封面主标题 64 / 章节大字 56 / 巨型数字 80-110 / 页面主标题 30 / 卡片小标题 22 / 正文 18-20 / 脚注 13。
- 巨型数字用 bold + 青色，与正文形成尺度跳跃。

## 5. 信息密度与留白
- 常规内容页留白 ≤35%；封面/封底允许 35-50%（围绕焦点）。
- 卡片内填充率 ≥85%（高卡片正文≥100字）。
- 禁止"均匀稀薄"；焦点元素周围留 ≥40px 呼吸。

## 6. 组件与配图
- 图标统一用 **FAIcon**（不混用 Emoji）；危险相关用 `shield`/`exclamation-triangle`，流程用 `arrow-right`。
- 截图素材（L1/L2）取自项目真实截图，已复制到 `assets/`（英文命名）。
- 架构图/流程图/时间轴用 **内联 SVG**（结构化低语义，允许）。
