# CNCOPS 安装向导（NSIS）编译与使用说明

本目录包含把 `cncops-demo`（PyInstaller onedir 包）封装成**标准 Windows 安装程序**的脚本。

## 交付文件

| 文件 | 作用 |
|------|------|
| `cncops-demo.nsi` | NSIS 安装脚本（描述安装/卸载逻辑） |
| `build_installer.bat` | 一键编译批处理（自动定位 NSIS、定位源目录） |
| `cncops-demo.ico` | 应用图标（V2 自适应，7 尺寸），供 setup.exe / 卸载程序 / 快捷方式使用 |
| `安装包编译说明.md` | 本文件 |

## 提交 / 分发时交哪个文件

- **只能交一个文件时**：交 `installer/cncops-demo-setup.exe`（当前 **28,756,860 字节 ≈ 27.4 MB**，2026-11-04 19:52 编译，含 L3 闸门与空态修复）。它是自包含安装向导：双击 → 下一步 → 完成，自动建桌面/开始菜单快捷方式并带卸载程序；评审机**不需要 Python、不需要联网、不需要源码**。
- **不要只交** `dist/cncops-demo/cncops-demo.exe`——onedir 包缺 `_internal` 依赖会启动失败。
- **允许交绿色压缩包时**：压缩**整个** `dist/cncops-demo` 目录（约 83 MB），压缩前先删掉运行时生成的 `data/`、`logs/` 残留，避免把本机演示记录带给评委。
- **配套材料**（另交，不混进 exe）：路演 PPT（桌面 `cncops-agent路演.pptx`，含第 9 页内嵌视频）、`docs/DEMO_3MIN.md` 三分钟演示脚本、`项目总结与使用说明.md`。
- 未做代码签名，首次运行若被 SmartScreen 拦截，点「更多信息 → 仍要运行」即可。

## 安装包能做什么

- **安装到 `C:\Program Files\cncops-demo`**（需要管理员权限，脚本已 `RequestExecutionLevel admin`）。
- 创建 **开始菜单文件夹 + 桌面快捷方式**，快捷方式工作目录设为安装目录。
- 完成页支持「**立即启动**」与「**查看使用说明**」勾选。
- 在「控制面板 → 卸载或更改程序」中可见，**带标准卸载程序** `uninstall.exe`。
- 卸载时清理程序文件与快捷方式；**刻意保留**用户数据（`%LOCALAPPDATA%\cncops-demo` 里的诊断记录/数据库），避免误删现场演示数据。

## 应用图标（V2）

- `cncops-demo.ico` 是唯一图标源，含 16/24/32/48/64/128/256 七个尺寸；大尺寸保留双同心环与网格，小尺寸自动简化为盾牌，避免 16px 糊成色块。
- **三处生效**：① 主程序 `cncops-demo.exe` 由 `cncops-demo.spec` 的 `icon=` 内嵌；② 安装向导与卸载程序由 `MUI_ICON` / `MUI_UNICON` 内嵌；③ 桌面与开始菜单快捷方式由 `CreateShortCut` 指向随程序安装的 `cncops-demo.ico`。
- 更换图标：替换 `installer/cncops-demo.ico`（`assets/` 留有同版备份），再依次重跑 PyInstaller 构建与 `build_installer.bat` 即可。

## 编译步骤

1. 安装 NSIS（Nullsoft Scriptable Install System）：
   https://nsis.sourceforge.io/Download  → 下载并安装最新版。
2. 确保已存在打包源目录 `..\dist\cncops-demo`（即 PyInstaller 构建产物，含 `cncops-demo.exe` / `_internal` / `使用说明.txt` / `config` / `web`）。
   - 若还没有，请先按项目文档执行 PyInstaller 构建（命令见 `cncops-demo.spec` 或项目总结）。
3. 双击 `build_installer.bat`（或在命令行运行它）。
4. 编译成功后在 `installer/` 下生成 **`cncops-demo-setup.exe`**。

> 也可手动指定源目录（覆盖默认路径）：
> `makensis /DSRC="D:\你的路径\dist\cncops-demo" cncops-demo.nsi`

## 已知注意事项

- **运行库**：PyInstaller onedir 通常已把所需运行库打进 `_internal`；极少数干净机器若报「缺少 VCRUNTIME140.dll」等，请安装
  [Visual C++ Redistributable](https://learn.microsoft.com/zh-cn/cpp/windows/latest-supported-vc-redist)。
- **SmartScreen / 杀毒误报**：未做代码签名的 PyInstaller 程序首次运行可能被 Windows SmartScreen 或杀软拦截。属正常现象，点「仍要运行」即可；要消除需购买代码签名证书并对 exe 与 setup.exe 签名。
- **数据落盘位置**：程序安装到只读的 Program Files 后，诊断数据库与日志会自动改写到
  `%LOCALAPPDATA%\cncops-demo`（由 `src/cncops/paths.py` 的 `_writable_base()` 保证），无需担心权限问题。

## 与「绿色 zip 包」的区别

| 维度 | 绿色目录包（直接压缩 `dist/cncops-demo`，当前不随项目提供） | 安装向导（`cncops-demo-setup.exe`） |
|------|------|------|
| 安装 | 解压即用，无注册表 | 标准安装，写注册表、可经控制面板卸载 |
| 快捷方式 | 无，需手动建 | 桌面 + 开始菜单自动创建 |
| 卸载 | 删文件夹即可 | 经卸载程序清理 |
| 适用 | 快速试用、U 盘携带 | 正式分发、给非技术用户 |
